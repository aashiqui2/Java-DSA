min no of nodes in a binary tree of height h is h+1
max no of nodes in a binary tree of height h is 2^(h+1)-1

max height of a binary tree with n nodes is n-1.
min height of a binary tree with n nodes is log(n+1)-1.
take ceil values because thw whole values in log will have even numbers

min no of nodes in a full binary tree of height h is 2h+1.
max height of a full binary tree with n nodes is (n-1)/2

min no of nodes in complete binary tree of height h is 2^h.
max height of a complete binary tree with n nodes is logn
